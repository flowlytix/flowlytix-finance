# Flowlytix Financial Intelligence

Plan your salary, check in at month end, and see what to do next: budget, salary & tax forecast,
net worth, and credit card and loan pay-off intelligence.

Live at **https://finance.flowlytix.co**

- Static site: a single `index.html`, no build step (Vercel framework preset: **Other**).
- All data is saved in the visitor's browser (localStorage). Nothing is sent to a server.
- Users can download / restore a backup in **Setup › Backup**.
